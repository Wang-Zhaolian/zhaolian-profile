# 隐私与备份

应用服务只监听本机回环地址。首次下载包含程序和默认空白结构，不包含作者的资料或登录状态。

## 哪些资料会离开本机

日常录入和附件保存仅写入本机。主动调用 AI 时，发送当次选择的文字和附件，以及界面说明的普通履历上下文；不自动发送联系方式、证明材料路径、旧草稿原文或其他附件。普通自定义字段会参与上下文，请勿在其中填写密码或其他敏感内容。

主动点击 GitHub 备份时，只上传履历文字、分类和表单配置、资料库标识及应用版本说明。包含已入库的待完善记录；证明材料字段、联系方式、附件原件、原笔记、处理历史、模型偏好、凭据和运行日志不上传。

AI 调用和 GitHub 备份是两个独立操作，配置其中一项不会自动启用另一项。

## 配置自己的私人备份

1. 安装 [Git](https://git-scm.com/downloads) 和 [GitHub CLI](https://cli.github.com/)。
2. 完成一次 GitHub CLI 登录：`gh auth login --web`。登录由 GitHub CLI 管理，不在本应用填写令牌。
3. 在自己的 GitHub 账号创建一个**私有、空白**仓库，不初始化 README 或许可证。
4. 在应用设置填写 `用户名/仓库名`，保存，核验后点击备份。

备份使用资料目录内独立的 Git 工作目录，不修改公开源码仓库。每次上传都核对仓库完整名称、私有状态和推送权限；不会自动创建仓库，不会强制覆盖冲突。

首次连接非空仓库时，需要其备份标识与当前资料库一致。其他项目、另一份资料库或远端出现不同更新时会停止；本机录入始终保留。只有推送成功才更新成功时间，失败的本地提交会保留以便重试。

GitHub 私有仓库仍由 GitHub 提供服务；请自行控制访问权限。附件与原件应另做本机完整恢复副本。
