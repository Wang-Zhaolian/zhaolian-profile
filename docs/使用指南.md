# 使用指南

## 第一次使用

从 [Releases](https://github.com/Wang-Zhaolian/zhaolian-profile/releases/latest) 下载 Windows ZIP，完整解压，双击主程序。浏览器页面仅供本机访问。重复启动会复用同一份资料库的服务；关闭浏览器标签不会退出程序，请使用页面里的退出按钮。

首次使用默认创建空白资料库。可以先填写个人资料，再进入分类添加经历。姓名和普通履历文字可能进入你主动配置的私人备份；电话号码、邮箱等联系方式只存本机。

## 记录、分类与查找

在总览进入分类，新增记录后统一保存。日期不是必填，不确定的事实不要编造；资料不全时保留“待完善”。

“管理分类”可以新增、改名、排序、归档和恢复分类。每类字段支持新增、改名、顺序、必填及删除，点击该分类的“保存设置”一次提交。有历史值的字段不能直接更改类型；删除字段保留历史值。

卡片和列表按当前表单顺序展示前五项，第一项作为标题。检索只匹配标题字段，不能用备注或分数命中记录。排序支持可识别数字、带常见单位的数字和日期，空值始终在后；不提供拼音排序。

## 草稿箱与 AI

一条草稿可以混合文字及多个附件。单文件不超过 50 MB，一条草稿最多十个附件、附件总计不超过 200 MB；一次 AI 附件输入另受 50 MB 及模型上下文限制。超限时应选择页码或拆分，不会静默截取。

先在“备份与设置”使用自己的 ChatGPT 账号授权，再选择可用模型。模型选择保存在本机，各入口共用；原模型不可用时需要自行重新选择。

点击生成建议前请核对界面披露的发送范围。AI 结果仅是候选，可以改分类、改字段值、删除候选，再统一保存。成功采纳的候选进入分类，默认待完善；未处理和失败项保留。全部处理完成的资料退出草稿列表，原件仍保留在本机用于恢复。

Office 转换需要安装本机 Microsoft Office 对应组件；遇到超时或转换失败时，请自行另存为 PDF。AI 可能识读错误，尤其是手写、表格和图片，务必对照原件。

## 更新、搬家与恢复

默认资料位置：`%LOCALAPPDATA%\ZhaolianProfile`。设置页也会显示实际位置；使用自定义启动目录的旧用户继续使用原目录。

更新前先保存记录、退出旧程序，并复制整个资料目录作恢复副本。解压新版本并启动即可，程序资源更新不会覆盖资料。不要把两份不同版本同时用于编辑同一个资料库。

需要搬家或从本机副本恢复时，在程序退出后把完整资料目录复制到新位置，再通过 `--home` 指定该目录，或放回默认位置。不要把旧程序文件覆盖到新版本目录。ChatGPT 凭据由 Windows 当前用户加密，换电脑后需重新登录。

GitHub 文本备份不包含附件、联系方式和草稿原件，不能代替完整的本机恢复副本。本版不提供一键远端恢复。

## 常见问题

**页面没有自动打开**：等待启动完成；查看资料目录 `.runtime/server.log`。反馈时只提供脱敏的报错片段。

**提示旧版仍在运行**：先在旧页面保存输入，再点击退出，之后启动新版。程序不会自动关闭旧窗口。

**AI 授权或请求失败**：账号资格与模型取决于服务端结果，可重试登录或查看 ChatGPT 用量。手工录入和本机保存仍然可用。

**备份失败**：核对 Git、GitHub CLI、登录账号、私有仓库名称和推送权限。远端有不同提交时会停止，避免覆盖；本机记录不受影响。

**Windows 显示未识别的应用**：当前试用包没有代码签名。请核对官方下载地址与 SHA256，不需要关闭安全软件。
