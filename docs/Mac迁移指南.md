# 把整个履历库搬到 MacBook

## 在 Windows 上完成复制

先保存资料并通过页面的退出按钮关闭平台，再复制整个“昭濂个人履历库”文件夹。里面应同时包含：

- 程序源码与使用说明。
- “个人资料”：真实履历、分类设置、联系方式、草稿原件和附件。
- `portable-library.json`：用相对位置找到这一份资料，不要删除或单独改动。
- “启动程序”：M 系列和 Intel 对应的 Mac 启动 ZIP。

迁移前恢复 ZIP 可以一起带走。它含私人资料，不适合公开上传。

## 在 Mac 上打开

1. 把整个文件夹放到本机“文稿”或其他可写位置，不要直接从只读磁盘映像运行。
2. 打开“关于本机”：芯片是 Apple M 系列时选择名称带 `arm64` 的 ZIP；处理器是 Intel 时选择 `x86_64` 的 ZIP。
3. 在“启动程序”中双击对应 ZIP 解压，再双击里面的“昭濂个人履历库.app”。不需要另装 Python。
4. 浏览器自动打开后，进入设置核对“本机数据位置”指向随文件夹保存的“个人资料”。

请把解压后的 App 保持在这个文件夹内，不要单独移到“应用程序”。这样移动整套文件夹时，仍能找到同一份履历，不会新建空库。可以为 App 创建替身放到桌面。

也可以使用“在Mac上开始.command”自动选择架构并解压。如果复制方式没有保留脚本执行权限，直接按上面的 ZIP／App 方法打开即可。

本版 App 使用临时签名，未经过 Apple 开发者公证。如果系统提示无法验证开发者，请先核对来源与 SHA256；确认可信后，按 [Apple 官方方法](https://support.apple.com/zh-cn/102445) 在“系统设置 → 隐私与安全性”允许此 App。无需关闭系统安全保护。

## AI 第一次重新登录

Windows 的加密登录依赖原 Windows 用户，不能直接由 Mac 解密。Mac 首次点击“使用 ChatGPT 登录”重新授权即可，以后在同一台 Mac 上会记住登录并自动续期。

Mac 登录信息单独加密保存于 `~/Library/Application Support/ZhaolianProfile/chatgpt`，保护密钥放在系统钥匙串，不随资料文件夹公开或搬运。首次系统询问钥匙串访问时，请确认是本应用。

模型选择、排序与其他普通本机偏好随“个人资料”一起迁移；若原模型对当前账号不可用，需要自行重新选择。

## 图片、PDF 与 Office 附件

图片、PDF、文字和 Markdown 可直接使用。Mac 上 DOCX、XLSX、PPTX 转 PDF 使用 [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/)，可以安装到“应用程序”；不安装时自行把 Office 文档另存为 PDF 也能继续整理。转换采用独立进程和超时限制。

已存进草稿箱的附件原件会随资料移动。记录中手工填写的 `C:\...`、`D:\...` 等盘外路径不能自动变成 Mac 文件，请重新选择其对应文件；程序不会擅自改写原始事实或删除这些路径。

## GitHub 备份与日常更新

GitHub CLI 登录属于每台电脑，换 Mac 后需安装 Git／GitHub CLI 并重新登录，之后继续使用设置中自己的私有备份仓库。私人备份不包含联系方式和原件，完整迁移应复制整个资料目录。

换版本时保留“个人资料”和 `portable-library.json`，只更换程序。不要在两台电脑同时编辑两份复制品后互相覆盖；先确认哪一份更新，再复制完整资料。

Mac 启动包在实际 macOS 的 M 系列与 Intel 环境分别构建，不能把 Windows `.exe` 当作 Mac 程序使用。源码开发方式见“开发与打包”。
