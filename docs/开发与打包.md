# 开发与打包

内部 Python 包名和命令仍为 `academic_profile` / `academic-profile`，保留兼容性；对外名称为昭濂个人履历库，仓库为 `Wang-Zhaolian/zhaolian-profile`。

## 目录

| 内容 | 位置 |
| --- | --- |
| 后端源码 | `src/academic_profile` |
| 网页与晶体图标 | `templates`、`static` |
| 校验结构与兼容配置 | `schemas`、`profiles` |
| 虚构示例 | `sample_data` |
| 使用文档与展示图片 | `docs` |
| 测试、构建与验收工具 | `tests`、`scripts` |
| 构建产物（不提交） | `build`、`dist` |

空白资料库由初始化程序根据默认分类建立，不复制作者的 `data`。旧的简历生成接口明确返回功能已移除；保留的兼容模块和旧配置不构成可用的简历生成功能。

## 开发

```powershell
uv sync --frozen --extra dev
uv run academic-profile-desktop --home "D:\Zhaolian-Test-Library"
uv run pytest
```

`ZHAOLIAN_PROFILE_HOME` 环境变量也可指定默认资料位置，显式 `--home` 优先。程序资源按安装位置读取，资料目录无需包含网页、校验结构或应用源码。

新增的 `/api/backup/config` 通过 GET/PATCH 读取和保存本机仓库配置。`/api/health` 返回版本与资料库标识，启动器据此区分实例。现有记录接口继续采用原子写入与修改版本检查。

## Windows 构建

在 Windows x64 上安装 uv，然后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build_windows.ps1
```

脚本运行测试、收集第三方许可、打包程序，生成 Windows ZIP 和 SHA256。构建不会创建或改动桌面快捷方式。当前发布包未进行代码签名。

发布前运行 `uv run python scripts/check_release.py` 检查公开文件和 Git 历史，并在独立资料目录验收打包程序。发布 ZIP 放入 GitHub Releases，源码仓库不跟踪程序包、运行目录、凭据或使用者记录。

测试和界面演示只能使用临时或虚构资料；不要用开发者自己的资料库生成截图。`scripts/verify_ui_refinements.py` 使用模拟 AI，不调用真实 ChatGPT。
