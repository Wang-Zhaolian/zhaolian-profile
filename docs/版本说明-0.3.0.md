# 0.3.0 · 首个公众试用版

昭濂个人履历库面向 Windows x64 提供下载试用。

- 解压并双击启动，自动创建空白资料库；程序更新与资料保存分开。
- 中文履历管理、自定义分类与字段、草稿箱、附件和人工审核 AI 候选。
- 模型选择记忆、标题检索、数字与日期排序，以及卡片／列表前五项预览。
- 私有 GitHub 备份支持使用者自己的仓库，与公开源码彻底分开。
- 补齐中文使用指南、隐私范围、更新恢复方法和第三方许可说明。

下载 Windows ZIP 后完整解压，运行 ZhaolianProfile-0.3.0.exe。SHA256SUMS.txt 提供文件校验值，源码可使用页面自动提供的 Source code 下载。

默认资料位置为 Windows 当前用户的 %LOCALAPPDATA%\ZhaolianProfile。旧用户显式指定的资料目录仍可使用。更新前保存并退出旧程序，保留完整资料副本。

AI 需自行授权符合条件的 ChatGPT 账号，资格、模型和额度以实际结果为准。Office 转换需要本机对应 Microsoft Office 软件。GitHub 备份需要 Git、GitHub CLI 登录和私有仓库。

当前试用包未进行代码签名，其他操作系统未完成桌面验收；暂未添加开源许可证。平台不提供简历生成。
